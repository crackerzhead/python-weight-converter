# ⚖️ Python Weight Converter

A beginner-friendly Python console application that converts weight between **kilograms and pounds**. This project was created as part of my Python learning journey to practice user input, conditional statements, calculations, and basic input validation.

## 📌 Features

- Convert Kilograms (Kg) to Pounds (Lbs.)
- Convert Pounds (Lbs.) to Kilograms (Kg)
- Accepts user input through the console
- Validates whether the entered weight is a number
- Accepts uppercase and lowercase unit choices
- Displays the converted weight rounded to one decimal place
- Handles invalid unit input

## 🛠️ Concepts Used

- `input()`
- Variables
- `if / elif / else`
- Nested conditional statements
- `.isdigit()`
- `.upper()`
- `float()`
- Arithmetic operations
- `round()`
- f-strings

## 🚀 How to Run

### Requirements

- Python 3.x

### Run the program

```bash
python weight_converter.py
```

## 💻 Example

```text
Enter your weight: 70
Kilogram or Pounds? (K / L): K

```

Another example:

```text
Enter your weight: 154
```
